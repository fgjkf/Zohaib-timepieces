## Getting Started

This repository contains the official website for Zohaib Timepieces. 

### Prerequisites

- Web browser (modern versions)
- Internet connection

### Installation

1. Clone the repository:
```bash
git clone https://github.com/fgjkf/zohaib-timepieces.git
```

2. Navigate to the project directory:
```bash
cd zohaib-timepieces
```

3. Open `index.html` in your web browser or serve it using a local server.
